# Deluxe Solution — Animated Single-Page Website

Lightweight, modern, animated single-page website for **Deluxe Solution**, Sinhgad Road, Pune.

## Included:
- Animated Hero with Interactive Equipment Showcase Switcher
- Specialized Repair Services (Laptop, CCTV, Currency Machines, Printers)
- Interactive Diagnostic Fault Guide
- Transparent "Why Choose Us" & 4-Step Process
- Verified Workshop Info & Google Maps Embed
- Self-Contained Repair Enquiry Form (Generates Ref ID, saves to localStorage, with 1-Click WhatsApp Instant Reply)
- Floating WhatsApp & Click-to-Call Buttons

## Running Locally:
```bash
npm install
npm run dev
```

## Direct Deployment:
Upload the contents of `dist/` directly to cPanel `public_html/`, Netlify, Vercel, or GitHub Pages.
